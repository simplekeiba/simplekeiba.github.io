以下の手順を順番に実行する。いずれかのステップが失敗した場合は、その時点で処理を停止し、失敗した理由を日本語でユーザーに報告すること。次のステップには進まない。

1. `git diff` の内容を確認し、変更点を日本語で要約する
2. `npx tsc --noEmit` を実行し、エラーが0件であることを確認する
3. PowerShellで `$env:TZ="UTC"; npm run build; Remove-Item Env:TZ` を実行してビルドし、`dist/` 内の時刻表示が日本時間（JST）になっていることを確認する
4. 1〜3がすべて通過したら、変更内容を日本語のメッセージでコミットする
5. `git push origin main` を実行する
